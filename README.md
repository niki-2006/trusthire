# TrustHire 🔐

## AI Skill Authentication & Credentials Verification

TrustHire is an AI-powered platform designed to help recruiters
verify candidate credentials and identify potentially fake certificates.

## 🚀 Features

- Certificate verification
- OCR-based certificate text extraction
- Resume analysis
- Skill verification
- Student and recruiter dashboards
- Secure credential management

## 🛠️ Tech Stack

- Python
- HTML
- CSS
- JavaScript
- OCR
- Machine Learning
- SQL

## 🎯 Problem Statement

Recruiters often face difficulties verifying certificates and
evaluating whether candidate credentials are genuine.

TrustHire aims to simplify this process using AI-assisted
credential verification.
